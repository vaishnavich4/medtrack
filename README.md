MedTrack - Medicine Stock Inventory and Expiry Date Tracker

A professional web app built with Python Flask and MySQL.

Features
- Role based login (Admin, Staff, Doctor)
- Medicine inventory management
- Expiry date alerts
- Dashboard with graphs

How to run
1. Install Python and MySQL
2. Run: pip install flask mysql-connector-python
3. Run: python app.py
4. Open: http://127.0.0.1:5000

Login Details
- Admin: admin123
- Staff: staff123
- Doctor: doctor123
